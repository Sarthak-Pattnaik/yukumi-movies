# 🎬 Yukumi Movies

A full-stack social movie tracking platform where users can discover films, maintain personalized watchlists, rate and review movies, follow other users, and engage with a movie-loving community.

Built with a modern cinematic UI inspired by platforms like Letterboxd, featuring personalized profiles, community activity feeds, social interactions, and movie discovery powered by TMDB.

![Yukumi Movies](./frontend/public/hero.png)

---

## ✨ Features

### 🎥 Movie Discovery

* Search movies using TMDB API
* Browse trending movies
* View detailed movie information
* Explore cast, ratings, and movie metadata

### 📚 Personal Movie Tracking

* Add movies to your list
* Track watching status

  * Watching
  * Completed
  * Plan to Watch
  * Dropped
* Rate movies
* Mark favorites
* Edit or remove entries

### 📝 Reviews & Ratings

* Write movie reviews
* Edit and delete reviews
* Like reviews from other users
* View reviews on movie pages

### 👥 Social Features

* Follow and unfollow users
* User profiles with customizable:

  * Avatar
  * Tagline
  * Bio
* Community activity feed
* User search functionality
* Notifications for social interactions

### 📊 Statistics Dashboard

* Movies tracked
* Movies completed
* Favorites count
* Reviews count
* Average rating

### 🎨 Modern UI

* Dark cinematic theme
* Emerald accent color palette
* Responsive design
* Glassmorphism-inspired components
* Smooth hover animations
